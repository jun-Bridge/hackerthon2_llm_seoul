# resource/ — 자료·에셋 원본

코드가 아닌 입력물을 둔다.

- `samples/` — 개발·테스트용 샘플 이미지·픽스처
- 시안 스크린샷·스펙 시트 등 작업 원본

**여기 있는 건 빌드 산출물에 포함되지 않는다.** Vite 루트가 `src/frontend/`라
이 폴더는 번들에도, 배포되는 `dist/`에도 들어가지 않는다.
프로덕션에서 `/resource/...`를 요청하면 이미지가 아니라 `index.html`이 돌아온다(SPA 폴백).

**화면에 실제로 나가는 이미지는 `src/frontend/public/`에 둔다** — 거기 있는 파일만
`dist/`로 복사돼 `/파일명`으로 서빙된다. 옮길 때는 먼저 줄여서 넣는다
(전체 번들이 250KB인데 원본 사진 하나가 1MB를 넘는 경우가 있다).

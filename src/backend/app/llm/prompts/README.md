# llm/prompts/ — 프롬프트 템플릿

프롬프트를 코드에서 떼어낸다. 문구 수정이 로직 변경으로 번지지 않게.

구현 예정
- `system.md` — 공통 시스템 프롬프트 (서비스 성격·톤·거절 기준)
- `chat.md` — 일반 대화
- `document_generate.md` — 대화 맥락에서 문서 초안 생성 (캔버스 진입)
- `edit_selection.md` — **편집형 캔버스의 핵심.** 문서 전문 + 선택 범위 + 사용자 지시 → 해당 부분만 고친 결과
- `loader.py` — 템플릿 로딩·변수 치환

각 템플릿의 입력 변수는 파일 상단에 주석으로 명시한다.

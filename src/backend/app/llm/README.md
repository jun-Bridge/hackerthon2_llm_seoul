# llm/ — LLM 클라이언트

**모든 모델 호출은 이 폴더를 거친다.** 모델·서빙 백엔드 교체가 여기 안에서 끝나야 한다.

구현 예정
- `base.py` — 인터페이스(Protocol): `complete()`, `stream()`. 서비스는 이 타입만 안다.
- `gptoss.py` — gpt-oss-120b 구현. OpenAI 호환 엔드포인트(`LLM_BASE_URL`)에 붙는다.
- `fake.py` — 테스트용 결정론적 스텁. 유닛 테스트는 실제 모델을 부르지 않는다.
- `prompts/` — 프롬프트 템플릿 (아래 참조)

서비스 코드에 프롬프트 문자열을 박지 않는다.

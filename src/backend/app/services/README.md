# services/ — 도메인 로직

이 프로젝트의 실제 내용이 있는 곳. **테스트의 주 대상.**

구현 예정
- `chat_service.py` — 대화 저장, 컨텍스트 조립(이전 메시지 + 시스템 프롬프트), LLM 스트리밍 중계
- `document_service.py` — 문서 생성·조회, 버전 스냅샷 적재, 특정 버전 복원
- `canvas_service.py` — 선택 영역 편집. 원문 + 선택 범위 + 지시 → `edit_selection` 프롬프트 → LLM → **새 버전으로 저장**(원본 덮어쓰지 않음)

규칙
- 외부 자원(DB·Redis·LLM)은 생성자로 주입받는다. 서비스 안에서 직접 만들지 않는다 → 유닛 테스트에서 fake로 갈아끼운다.
- 트랜잭션 경계는 여기서 잡는다. repository는 트랜잭션을 모른다.

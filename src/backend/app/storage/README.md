# storage/ — 파일 저장 추상화

첨부 이미지의 바이트가 사는 곳. **DB에 이미지를 넣지 않는다.**

구현 예정
- `base.py` — 인터페이스: `put(key, bytes, content_type)` · `get(key)` · `delete(key)`
- `local.py` — 로컬 볼륨 구현 (개발용)
- `s3.py` — 배포용 (나중)

원칙
- 저장소 교체가 **이 폴더 안에서 끝나야 한다.** 밖에서는 `base.py` 인터페이스만 안다.
- DB에는 `storage_key`만 남는다.
- 저장소 URL을 클라이언트에 직접 노출하지 않는다. 항상 API를 거쳐 **소유자 확인 후** 내보낸다.
- 업로드는 서버에서 형식·크기를 검증한다. 확장자만 믿지 않는다.

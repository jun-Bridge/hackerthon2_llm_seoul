# components/canvas/ — 문서 편집(캔버스)

우측 화면 전체. **마크다운 문서 편집기.**

- `editor/` — 본문 편집, 블록 조작, 제안 diff 표시
- `toolbar/` — 문서 작업 (다운로드·복사·잘라내기·붙여넣기·실행취소·일괄 서식)

**LLM 편집안 생성 중과 제안 대기 중에는 블러 + 편집 잠금.** 잠금 상태는 SSE로 온다.
SSE 해제 통지를 놓칠 수 있으므로 **클라이언트에도 자체 타임아웃**을 둔다.

LLM은 문서를 직접 바꾸지 못한다. diff를 보고 사용자가 **적용/취소**를 누른다.

# styles/ — 스타일

| 파일 | 무엇 |
|---|---|
| `index.css` | 전역 리셋·타이포·앱 프레임·상태 배지(`status-pill`)·애니메이션 |
| `layout.css` | 페이지 본문·하단 탭 레이아웃 |
| `home.css` | 홈 화면 |
| `auth.css` | 로그인·가입 |

컴포넌트 스타일은 대부분 JSX 인라인으로 들어가 있고, **여러 화면이 공유하는 것만** 여기 둔다.

`status-pill status-<상태>` 클래스는 민원 상태 7종에 각각 색이 정의돼 있다.
상태를 추가하면 여기에도 색을 넣어야 한다 — 없으면 배지가 회색으로 나온다.

# pages/ — 화면

| 파일 | 무엇 |
|---|---|
| `LandingPage.jsx` | 비로그인 첫 화면 |
| `AuthPage.jsx` | 로그인·가입. 학교를 고르면 **도메인이 잠기고** 아이디만 입력한다 |
| `MainPage.jsx` | 로그인 후 컨테이너. 탭으로 아래 화면들을 렌더 + 챗봇 모달 |
| `HomePage.jsx` | 인사말·캠퍼스 지도(민원 위치 핀)·내 민원 요약·최근 민원 |
| `BoardPage.jsx` | 학교 전체 민원 게시판 (카테고리 필터·검색) |
| `StatusPage.jsx` | 내가 접수한 민원 |
| `AdminPage.jsx` | 관리자 통계·목록·상태 필터 |
| `ProfilePage.jsx` | 계정 정보·교직원 인증·로그아웃 |

## 규칙

- **역할이 화면을 정한다.** 앱은 `getMe()`의 `role`을 먼저 받고 그 뒤에 그린다.
  학생/관리자 전환 버튼 같은 건 만들지 않는다 — 계정이 곧 역할이다.
- **목록·통계를 화면이 캐시하지 않는다.** 다른 사용자가 계속 바꾸므로 그릴 때 다시 읽는다.
  상태 변경 API는 갱신된 `Complaint`를 돌려주므로 **그 행만 갈아끼우고** 통계만 따로 받는다.
- **학교를 신경 쓰지 않는다.** 서버가 세션의 `school_id`로 전부 필터링한다.
  `school_id`를 보내지도 않고 보내도 무시된다.
